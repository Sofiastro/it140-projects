## Theme and Storyline

**Theme:**  
Glitch Museum Escape is a surreal, digital adventure set inside a corrupted virtual museum. The player, known as the Debugger, must restore stability to the system by collecting six lost artifacts scattered across distorted rooms. Each artifact repairs a different part of the museum’s broken code.

**Storyline:**  
The player begins in the Boot Lobby, a safe loading zone within the Glitch Museum. From there, they explore corrupted exhibits—each holding a fragment of reality. The Debugger must gather all six stabilizer artifacts to unlock the Core Vault and confront the Glitch Warden, a rogue AI that threatens to erase the museum entirely. Entering the Core Vault without all artifacts results in deletion.

## Rooms

- **Boot Lobby (Start Room):** No item. The safe entry point where the player begins.  
- **Pixel Hallway:** Contains the Quantum Key. A flickering corridor of shifting pixels.  
- **Static Theater:** Contains the Memory Shard. A looping projection room filled with broken visuals.  
- **Echo Gallery:** Contains the Time Fragment. A mirrored hall of repeating sound waves.  
- **Fractured Archive:** Contains the Signal Prism. A shattered vault of corrupted data.  
- **Mirror Loop Chamber:** Contains the Patch Module. A recursive room that endlessly reflects itself.  
- **Broken Clock Room:** Contains the Reality Anchor. A warped chamber where time runs backward.  
- **Core Vault (Villain Room):** No item. The final chamber housing the Glitch Warden. The player must enter only after collecting all six artifacts.

## Goal

The player wins by collecting all six stabilizer artifacts—Quantum Key, Memory Shard, Time Fragment, Signal Prism, Patch Module, and Reality Anchor—and entering the Core Vault to defeat the Glitch Warden. Doing so restores the system and frees the Debugger from the Glitch Museum.
